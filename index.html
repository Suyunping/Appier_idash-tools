🔍 iDASH 素材檢核

批量上傳素材，自動比對 iDASH Banner 允許尺寸清單。判斷哪些可直接上傳、哪些需要 Resize 或壓縮、哪些需要回報 AM。支援批量處理並下載 ZIP，檔名完全不變。

尺寸檢核 Resize PNG → JPEG 壓縮 批量下載 ZIP 回報 AM 清單

🎞 GIF 批次處理

批量修改 GIF Loop 次數（預設改為 5 次）並壓縮到目標大小（預設 300KB）。大小符合的只改 Loop 不重新編碼，超過大小限制的自動縮小尺寸並重新編碼。

Loop 次數修改 壓縮 < 300KB 批量下載 ZIP 不重新編碼（小檔）
→
🎬 影片 Endcard 截圖

批量截取影片最後一幀作為 Endcard 素材。可設定從結尾前幾秒截圖、輸出格式（JPEG / PNG / WebP），並自動壓縮到目標大小。批量打包 ZIP 下載。
